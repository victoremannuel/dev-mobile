# Calc

Aplicativo em Expo para somar, subtrair, multiplicar e dividir dois números. O histórico fica salvo no dispositivo e pode ser consultado na segunda tela.

## Como executar

```bash
npm install
npx expo start
```

Abra o aplicativo no Expo Go pelo QR code ou execute em um emulador. Também é possível usar `npm run web`.
