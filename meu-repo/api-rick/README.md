# Guia de Rick and Morty

## Tecnologias

React Native, Expo, JavaScript, React Navigation e Fetch API.

## Pré-requisitos

Node.js e npm. Para executar em um dispositivo, é possível utilizar o aplicativo Expo Go; para emuladores, é necessária a configuração do ambiente Android ou iOS.

## Instalação e execução

```sh
npm install
npm start
```

No terminal do Expo, utilize as opções apresentadas para abrir no dispositivo, emulador ou navegador. Também é possível executar `npm run android`, `npm run ios` ou `npm run web`.

As telas e componentes estão em `src/screens` e `src/components`; as consultas à API estão em `src/services`.
